Dividend Income Ledger  ·  Jesus A. Sanchez Davila

Plan the income. Size the capital.

Set a target net annual dividend income and a tax rate, and this ledger spreads it across your ETFs, tells you how many shares and how much capital each one needs, and lays out the month‑by‑month payout calendar the combination actually produces. Add, edit, or remove funds freely — the four originals stay one click away via "Reset to defaults."

02 — Holdings

Fund data

Name, ticker, ISIN, price, gross dividend/share, and payout months are all editable. Search for a fund above or click "+ Add fund" below to start building your own list.
Each fund remembers which of the two providers it was added from (shown next to its live-price status) and refreshes from that one. Eulerpool covers European UCITS ETFs well; Twelve Data has broader global/US stock coverage and a higher free-tier limit. Funds with no ISIN/ticker filled in below are skipped and keep their manual price.
Eulerpool: pasting an ISIN tries the matching endpoint first for whichever type is selected above (falls back to the other type's endpoint if that one 404s); a name/ticker falls back to a best-effort search call whose exact path isn't confirmed — check the debug panel if it comes up empty. Twelve Data: searches by name/ticker only (no ISIN support) via its symbol_search endpoint. Requires that provider's API key above.
